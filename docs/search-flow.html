Filter scope

The dashboard/API supports metadata filters. The current terminal command searches without filters. Each backend applies filters before selecting its exact top-K results.

Evaluation scope

Exact-neighbor metrics compare with NumPy. Relevance metrics use SciFact’s labeled queries and the relevant documents available in the filtered sample. Unlabeled relevance is shown as N/A.
